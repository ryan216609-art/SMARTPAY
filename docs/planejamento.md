# Planejamento por fases

1. **Ecossistema:** mapear atores, fluxo de pagamento e consentimento; simular o provedor financeiro.
2. **Segurança:** cadastro, login, hash de senha, JWT, autorização, minimização de dados e revogação.
3. **Blockchain:** token SPAY em rede local, testes de saldo, transferência e eventos.
4. **Integração:** conectar frontend, API e contrato; testar o fluxo ponta a ponta e preparar a demonstração.

## Papéis sugeridos
- Analista de Ecossistema: requisitos, atores, consentimento e Open Finance simulado.
- Guardian de Dados: LGPD, autenticação, autorização e revisão de segurança.
- Arquiteto Blockchain: Solidity, Hardhat, testes e implantação local.
- Integrador: React, APIs, integração e documentação de execução.

Todos os integrantes devem conhecer a arquitetura geral para a defesa.
